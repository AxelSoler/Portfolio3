# Axel Soler's Personal Portfolio

This is my personal portfolio website built to showcase my projects, work experience, and skills.

## 🚀 Live Page

[Link to live page](https://axelsoler.dev/)

## ✨ Features

*   **Responsive Design:** The website is fully responsive and works on all screen sizes.
*   **Dark/Light Theme:** Switch between dark and light mode for a better user experience.
*   **Internationalization:** The content is available in both English and Spanish.
*   **Sections:**
    *   **About Me:** A brief introduction about myself, my skills, and my background.
    *   **Projects:** A list of my projects with links to the live demo and source code.
    *   **Experience:** My work experience and education.
    *   **Contact:** A form to get in touch with me.

## 🛠️ Technologies Used

*   **[Next.js](https://nextjs.org/):** A React framework for building server-side rendered and static websites.
*   **[React](https://reactjs.org/):** A JavaScript library for building user interfaces.
*   **[TypeScript](https://www.typescriptlang.org/):** A typed superset of JavaScript that compiles to plain JavaScript.
*   **[Tailwind CSS](https://tailwindcss.com/):** A utility-first CSS framework for rapid UI development.
*   **[next-intl](https://next-intl-docs.vercel.app/):** A library for internationalization in Next.js.
*   **[next-themes](https://github.com/pacocoursey/next-themes):** A library for adding dark mode to Next.js applications.

## 📦 Getting Started

### Prerequisites

*   [Node.js](https://nodejs.org/en/) (v22 or higher)
*   [npm](https://www.npmjs.com/)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/AxelSoler/Portfolio3.git
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

To run the development server, use the following command:

```bash
npm run dev
```

This will start the development server at `http://localhost:3000`.

## 🚀 Deployment

The website is deployed on [](https://www.netlify.com/). The deployment settings are configured in the `netlify.toml` file.

*   **Build command:** `npm run build`
*   **Publish directory:** `.next`

## 📜 Scripts

*   `dev`: Starts the development server.
*   `build`: Builds the application for production.
*   `start`: Starts a production server.
*   `lint`: Lints the code using ESLint.
